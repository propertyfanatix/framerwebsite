# Shalinthia.com Framer Blueprint Package — v2

This package supersedes the prior CLOSED IN 60™ / CLOSED IN 60 DAYS website blueprint.

## Canonical Program

**Brooklyn 60-Day Seller Success Blueprint**

This is a structured 60-day marketing and coordination program for eligible properties. It is not a guarantee that a property will sell or close within 60 days.

Primary markets:
- Flatbush, Brooklyn
- East Flatbush, Brooklyn

Secondary market:
- Prospect Park South, Brooklyn

Program pillars:
- Tactical empathy
- Ethical urgency
- AI-assisted marketing

AI tools are assistive only. All public-facing content and market analysis must be reviewed and finalized by a licensed real estate professional.

## Non-Negotiable Language Rules

Never use:
- CLOSED IN 60™
- Closed in 60 Days
- 60-Day Guarantee
- guaranteed sale
- guaranteed closing
- guaranteed top dollar
- any statement promising sale price, profit, buyer behavior, lender timelines, appraisal outcomes, title clearance, or closing date

Use:
- Brooklyn 60-Day Seller Success Blueprint
- structured 60-day marketing and coordination program
- qualified homeowners
- eligible properties
- see if your property qualifies
- qualification review
- no-pressure qualification review

## Recommended Codex Workflow

1. Place this folder in the project root.
2. Ask Codex to read `README.md`, `MASTER_BLUEPRINT.md`, `COMPLIANCE_RULES.md`, `sitemap.json`, and `FRAMER_COMPONENTS.md`.
3. Tell Codex these files are the source of truth.
4. Build reusable systems first.
5. Build homepage + quiz + one neighborhood + one authority page + one conversion page.
6. Stop for review before duplicating the rest.

Preserve the existing visual brand, color palette, typography, logo treatment, spacing character, and overall personal-site feel.
